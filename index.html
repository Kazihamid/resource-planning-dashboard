The maintained Source baseline changes only when you explicitly choose Update Source Baseline or Set Valid Rows as Source. Import, Auto-Save, Save Plan, and ordinary edits do not change it. “Apply Proposed” commits the Proposed Plan to the dashboard Current Plan for comparison; “Reset to Source” restores the maintained Source baseline. Auto-Save is browser-local and can be cleared independently. Resource Involvement uses the full register, while Load Forecast uses the future horizon unless you select dates explicitly. Resource roles and Test Status are dashboard planning fields. Setup actions and register edits do not modify the uploaded source workbook; Reset to Source restores the embedded source plan.
